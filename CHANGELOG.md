# Release notes

## 0.1.0 beta 1 — first public beta

- GitHub tag: `v0.1.0-beta.1`
- Python package version: `0.1.0b1`
- GitHub release title: **AA2CG 0.1.0 — Public beta 1**
- Publish as a **pre-release**.

### Included

- Atomistic LAMMPS input inspection, species detection and 2D/3D visualization.
- Visual bead mapping, custom rules and automatic united-atom mapping.
- Per-interaction fitting controls, independent/coupled force matching and table preparation.
- LAMMPS setup generation and initialization smoke testing.
- Optional property-based refinement, Explore → Refine searches and study continuation.
- AA/CG validation, linked trajectory playback and portable project export.
- A manual Squalane tutorial guide and illustrated workflow documentation.

### Requirements and limitations

- The full workflow requires a compatible Linux/OpenMSCG environment; the Windows
  environment provides the interface and previews without OpenMSCG.
- LAMMPS must be installed separately for smoke testing and refinement simulations.
- The Squalane tutorial input-download link is not yet configured.
- This is a public testing release. Check installation and scientific results for
  your system; a completed workflow alone does not establish force-field quality.

See [README.md](README.md) for installation, workflow, licensing and citations.
